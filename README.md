# Посмотри в окно

Учебный проект Яндекс Практикума: поиск видео с видами из окон по городу и времени суток. CSS оформляет готовое приложение с поиском, переключением роликов, подгрузкой карточек и состояниями загрузки и ошибок.

Использованы HTML, CSS, Flexbox, псевдоклассы, псевдоэлементы и локальные шрифты. Исходная JavaScript-логика сохранена.

## Запуск

Откройте `index.html` через локальный HTTP-сервер, например `python -m http.server 8766`. Затем перейдите на `http://localhost:8766`. Для загрузки видео требуется интернет. Макет рассчитан на ширину от 1200 пикселей.

Репозиторий: https://github.com/ursu-nikita/posmotri-v-okno-ad
